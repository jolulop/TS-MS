# Docs v5.8 Promotion

## 1. Goal

Promote the current repository-aligned markdown specification set from `v5.7`
to `v5.8` after the user-initiated Copy Prev. Week implementation.

## 2. Scope

In scope:
- create the full `v5.8` markdown source-of-truth set
- repoint `AGENTS.md` and repository guidance to the `v5.8` files
- keep `v5.7` as a historical snapshot
- update versioned references in source-of-truth markdown files

Out of scope:
- editing legacy `.docx` documents
- changing historical completed plan files beyond normal historical retention

## 4. Version Notes

`v5.8` captures these newer implemented deltas relative to the v5.7 baseline:
- `Enable Copy Previous Week` is now a live Office-controlled feature
- `My Timesheets` exposes a user-initiated `Copy Prev. Week` action when enabled
- copied weeks must come from the employee's most recent approved earlier
  timesheet and still pass normal target-week validation

## 5. Validation

- confirm every source-of-truth markdown file has a `v5.8` counterpart
- confirm repo guidance points to the `v5.8` set
- confirm the changed feature docs are reflected in the new versioned files
