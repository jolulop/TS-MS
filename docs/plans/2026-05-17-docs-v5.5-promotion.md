# Docs v5.5 Promotion

## Goal

Promote the repository-aligned markdown documentation set from `v5.4` to
`v5.5` and update it to match the latest implemented UI and workflow behavior.

## Scope

In scope:

- create the full `v5.5` markdown source-of-truth set
- update version references and repository guidance
- capture the latest implemented navigation, System Management layout, and
  personal timesheet behaviors
- preserve unchanged technical areas while still promoting them to `v5.5`

Out of scope:

- deleting the existing `v5.4` markdown set
- changing code behavior
- editing the legacy `.docx` documents

## Approach

- copy the current `v5.4` source-of-truth files into a new `v5.5` set
- patch the new files with implemented behavior changes and updated version
  notes
- update `AGENTS.md` so the repo-level source of truth points to `v5.5`

## Verification

- search for stale `v5.4` source-of-truth references
- manually review the promoted `v5.5` files for consistency
