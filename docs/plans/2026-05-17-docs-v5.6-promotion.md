# Docs v5.6 Promotion

## Goal

Promote the repository-aligned markdown specification set from `v5.5` to
`v5.6` and align it with the latest implemented authorization and System
Management behavior.

## Scope

- create the full `v5.6` markdown source-of-truth set
- point `AGENTS.md` at the `v5.6` specification files
- update promoted docs to reflect:
  - `PROJECT_OWNER` project and assignment management in System Management
  - `PROJECT_MANAGER` project-assignment management in System Management
- keep older versioned markdown files as historical references

## Non-Goals

- deleting the existing `v5.5` markdown set
- changing implemented product behavior

## Verification

- confirm the `v5.6` file set exists for every source-of-truth document
- search for stale `v5.5` source-of-truth references in `AGENTS.md` and the new
  `v5.6` index set
